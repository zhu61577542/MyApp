# MyApp 第一版实施计划

状态：阶段 1、2 已完成；阶段 3～6 部分实现并已通过三端 Linux X11 CLI 流程；阶段 7 已接入 Fyne 原生窗口、系统托盘和发布包启动脚本，布局编辑和传输进度仍未完成

日期：2026-09-23

本轮：接入三机配置、设备数量限制、快捷键目标切换、文字与文件中转，拆分实时/批量 TLS 连接并绑定会话身份；全量竞态测试、vet、四平台构建、三端及双端 X11 CLI 验证通过，生成 0.1.3-alpha。前轮 52.2% 覆盖率是 0.1.2-alpha 的 Linux 语句覆盖率，不代表本轮覆盖率或功能完成比例。

## 阶段拆分

整体分为 8 个阶段，严格按依赖顺序推进：

### 阶段 1：工程基础与协议内核

交付：Docker 开发镜像、Go 模块、CLI、配置、设备身份、设备上限、协议帧及单元测试。
完成条件：Docker 内测试通过，并能交叉编译 Windows x64、macOS ARM64、Linux x64/ARM64。

### 阶段 2：发现、配对与信任

交付：局域网发现、短码配对、信任库、证书撤销、双向 TLS。
完成条件：两个独立容器可完成配对；签名发现报文通过真实 UDP 测试；已配对设备可完成双向 TLS 和协议帧交换；未配对、错误目标和撤销设备被拒绝。重连属于阶段 3。

### 阶段 3：连接与控制状态机

交付：心跳、重连、主从角色、屏幕布局、活动目标、紧急恢复和输入优先通道。
完成条件：三节点网络故障测试无卡键，输入通道不被批量传输阻塞。

### 阶段 4：三平台键鼠适配

交付：Windows Hook/SendInput、macOS Event Tap/CoreGraphics、Linux X11 与 Wayland portal/libei 能力检测和实现。
完成条件：三平台普通桌面完成移动、点击、滚轮、按键、组合键、边缘切换和断线释放测试。

### 阶段 5：文字剪贴板

交付：纯文字监听、版本同步、来源去环、暂停开关及平台快捷键语义。
完成条件：任意两台设备双向复制中文、英文和多行文字，无循环和旧内容覆盖。

### 阶段 6：文件和目录复制

交付：文件清单、流式传输、哈希、取消、恢复、缓存、冲突处理及三平台文件管理器适配。
完成条件：大文件、多文件、空目录、中文名称、断网、空间不足和冲突矩阵通过。

### 阶段 7：桌面界面与安装包

交付：系统托盘、设备列表、配对、屏幕布局、权限引导、传输进度，以及 Windows/macOS/Linux 安装包。
完成条件：新机器可完成安装、配对、使用和卸载；失败提示可操作。

### 阶段 8：端到端稳定与发布

交付：三机持续测试、安全复核、性能调优、日志脱敏、升级与发布文档。
完成条件：`PRODUCT.md` 成功标准全部有对应证据，未完成项不得标记发布。
