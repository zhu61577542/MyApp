## 1. 设计方向

用户已选择清爽原生风格：跟随系统明暗，低干扰，适合长期后台运行。沿用 MyApp 名称和蓝色鼠标指针品牌，不另起品牌或引入账号系统。当前没有 Figma 稿，本轮提供交互原型与本规格。

用户打开主窗口后，应能马上回答：连上了哪台电脑、现在控制谁、正在同步什么、遇到问题该怎么恢复。首页不默认显示 IP、监听端口、完整设备 ID 或命令行输出。

两端共享信息架构、状态语义和操作结果，分别适配窗口、菜单、快捷键、通知和设置入口。清爽原生描述使用体验，不承诺更换技术栈或系统原生控件。

## 2. 设计前基线与能力边界

本节记录上述代码基线的问题，不描述新版当前实现；已接入项见 `IMPLEMENTATION.md`。

现有 GUI 分为控制中心、设置、配对三个窗口；主要呈现配置和子进程状态。`app.go:106–157,323–329` 未读取实际连接和控制目标，因此不能将“配置已就绪”“进程运行中”改名成“已连接”。

`app.go:208–225` 的删除仅移除 peers 配置，不撤销信任；新界面必须区分断开、移除配置与撤销信任。设置当前保存后需重启服务，不能画成已即时生效的开关。`service.go:63–69` 仍使用进程终止，安全退出与释放输入需要补齐。

已具备核心配对、身份、双向加密、文字与缓存文件传输、基础原生输入和日志。实际在线状态流、GUI 发现、布局编辑与边缘切换、任务进度、即时暂停、开机启动和安全退出流程需要实现或接入。原型中的这些内容是目标体验，所有设备、任务与状态为示例。

## 3. 信息架构

| 一级入口 | 核心内容 | 默认主操作 |
|---|---|---|
| 设备 | 连接状态、当前控制目标、本机用途、已配对电脑、相对位置 | 添加电脑／调整位置 |
| 传输 | 当前任务、最近任务、发送方向、进度与失败原因 | 取消／重新发送／在文件夹中显示 |
| 权限与安全 | 按本机用途所需的权限、已信任电脑、撤销信任 | 去授权／重新检测 |
| 设置 | 名称、用途、共享选项、快捷键、外观、启动行为；高级诊断折叠 | 自动保存或明确的应用变更 |

首次启动进入设置向导，不向用户暴露初始化身份或 CLI 修复。Mac 的设置通过应用菜单和 Command+, 打开独立设置窗口；Windows 的设置固定在左侧导航底部。原型中的设置内容可以集中呈现，用于评审同一组选项。

## 4. 设备首页

主区自上而下：页面标题与“添加电脑”；会话状态和当前控制目标；电脑相对位置；已配对设备；独立的文字与文件同步选项。最多三台电脑包含本机，达到上限后解释原因并提供管理入口。

设备使用名称、系统标识、“本机／主电脑／子电脑”和有文字的状态标签。点击设备展开详情；IP、端口、短指纹及版本放在详情中，完整身份信息再次展开。离线电脑保留位置，不自动移除信任。

建立信任后自动连接并准备跨屏；鼠标仍在本机时不拦截输入，跨过相邻边缘才自动切换。切换前检查连接、权限和目标，显示当前目标及紧急退出快捷键。断线、权限撤销、停止控制和退出时先恢复本机控制；状态不得继续显示远端操作中。

布局用电脑屏幕示意表示真实相对位置。支持拖动，也提供左／右／上／下按钮替代；编辑时停止键鼠转发，预览、保存、取消分开。保存或取消后恢复此前的自动跨屏状态，不要求再次启用。

## 5. 首次使用与配对

1. 命名本机，默认采用系统设备名，可修改。
2. 选择用途：“用这台电脑的键鼠控制其他电脑（主电脑）”或“接受主电脑控制（子电脑）”。不显示 controller/agent。
3. 根据用途申请最小权限。拒绝后可继续查看设备与设置；允许独立运行的文字／文件功能，受影响的输入功能保持禁用并解释原因。
4. 查找同一局域网的电脑。没有结果时保留“通过 IP 添加”，并提供对端已启动、网络和防火墙检查步骤；不自动修改系统安全设置。
5. 两端显示同一组六位配对码和设备名称，分别主动确认。本机确认后显示“等待另一台电脑确认”；不能由本机替对端同意。取消、超时或任一端拒绝均不建立信任。超时由实际配对期限驱动，不用假倒计时。
6. 成功后自动结束向导并连接，默认相对位置可直接跨屏；主电脑可随时调整位置。

关闭配对窗口保留后台任务，但页面与托盘显示等待状态，并可取消；沿用现有后台成功后自动保存的行为。配对错误在对应步骤内显示原因、恢复动作和可展开详情。

## 6. 权限与平台习惯

| 项目 | macOS | Windows |
|---|---|---|
| 窗口 | 使用系统标题栏与左上角窗口按钮；内容侧栏与紧凑工具栏 | 保留系统标题栏、拖动区域、缩放、最大化与贴靠行为 |
| 设置 | MyApp 菜单、Command+,；分组设置窗口 | 左侧导航底部“设置”；同窗设置页 |
| 后台入口 | 单色菜单栏图标，点击显示状态和常用命令 | 托盘图标；单击、右击均打开菜单，通过“打开 MyApp”显示窗口 |
| 权限 | 输入监控、控制键鼠分别检测；说明当前系统实际使用的“辅助功能／设备控制”等名称 | 普通桌面可用性、网络连通性与防火墙引导；不诱导默认管理员运行 |
| 快捷键 | 展示 Control+Option+Esc；复制粘贴保留 Command | 展示 Ctrl+Alt+Esc；复制粘贴保留 Ctrl |
| 外观 | 系统字体、较圆润的分组、留白 | 系统字体、较紧凑的分组和导航选中标识；Windows 10 不依赖 Windows 11 材质 |

权限页必须有状态、受影响功能、授权步骤、系统设置入口和“重新检测”。深链不可用或系统名称变化时提供手工路径。未检测到授权与无法检测分开，不能将所有网络失败都解释成权限拒绝。返回应用后重新检查；需要重启时提供明确说明。

关闭主窗口继续后台运行，首次用一次轻提示说明从何处重新打开；Mac Command+Q 和“退出 MyApp”真正退出。后台入口包含连接摘要、当前目标、打开窗口、暂停全部共享、传输入口和退出。启动登录项默认不勾选，需用户主动选择。

## 7. 状态与危险操作

| 状态 | 呈现与动作 |
|---|---|
| 未设置／未配对 | 展示下一步，不显示伪在线状态 |
| 已配对但离线 | 显示“离线”，可查看详情、重试或撤销信任 |
| 正在连接 | 保留设备名称和取消操作，不允许开始控制 |
| 已连接、未控制 | 显示自动跨屏就绪，鼠标跨边缘即切换 |
| 正在控制 | 持续显示目标名称和紧急退出快捷键 |
| 正在重连 | 键鼠回到本机；显示实际重试信息和立即重试动作，不反复弹模态框 |
| 权限不足 | 就地显示恢复入口，仅禁用受影响功能 |
| 已暂停 | 输入留在本机，不读取或发送新共享内容；已批准的文件任务可完成，提供单独取消操作 |

文字同步、文件同步和键鼠控制是独立功能。暂停全部共享须在运行时生效且等待确认，不能只改配置；紧急退出键只负责立即结束键鼠控制，不顺带更改文字／文件偏好。

运行时需要重启才能生效的设置，显示“待应用”以及“应用并重新连接”。影响正在进行的控制或任务时，先说明影响并允许取消；失败回滚或保留原值，不能把未生效的值显示为已启用。

“断开连接”保留信任；“撤销信任并移除”明确说明需重新配对，并关闭现有会话、移除本机连接配置和撤销本地信任记录。旧证书无法继续连接本机；不保证离线对端自动删除其配置，对端可能保留无效记录。不能仅删除 peers 后宣称已撤销对端访问。

用户已确认接受上述 Fyne 托盘行为与本地撤销边界，不在本轮扩展托盘驱动或加入远程配置删除协议。

切换本机用途需先停止控制、处理在途任务并确认；不静默创建第二台主电脑。退出先停止新任务、结束捕获、释放按键、关闭连接，再结束进程；有任务时提供等待完成或取消任务后退出。优雅停止失败才进入明确的超时处理。

## 8. 文件任务与错误反馈

任务状态为准备、传输、校验、发布到剪贴板、完成、取消、失败。完成必须由接收端校验、提交并成功发布后的确认驱动。只发送完字节不能显示完成；校验或发布失败不得显示绿色成功。

任务展示文件／文件夹名、方向、设备名、实际字节进度；速度和剩余时间只在有可靠样本时显示。未知总量使用不定进度。接收结果默认在受控缓存中，用户仍需在目标电脑粘贴到想要的位置，不暗示已保存到桌面或最终目录。

中断后优先显示“重新发送”；当前未接入跨连接偏移协商，不提供“继续传输”承诺。取消需要双向确认并安全清理临时数据，取消中不立即标为已取消。失败示例为“目标电脑空间不足”，主操作为查看空间／重新发送，错误码收在详情。

日常成功不弹窗，主要通过任务与托盘状态反馈。权限预检只在页面显示具体项目，不发送系统通知；持续断线与传输失败使用持久去重，只有实际连接恢复才重置连接提醒。日志不记录剪贴板正文、文件内容、配对码或密钥；导出前显示保存位置，诊断包另行说明包含的信息。

## 9. 视觉与无障碍

使用系统字体；默认正文约 13–14 pt，标题按层级适度放大，8 pt 间距体系，蓝色用于主要动作和选中状态。浅深色分别定义文字、表面、边框与语义色，状态配文字和图标，不只依靠颜色。减少玻璃、渐变、大面积品牌色和无信息统计卡。

建议主窗初始约 1000×700，最小约 760×560，设置内容宽度受约束；保留系统缩放和高 DPI。所有关键操作可键盘完成，原生焦点环可见；布局操作有按钮替代，读屏可读当前目标和状态，尊重减少动态效果。原型为会话展示额外适配窄宽度，不代表桌面最小窗口承诺。

## 10. 实施顺序与验收边界

1. 接入真实状态事件和能力模型：身份、信任、进程、会话、控制目标、权限、任务与设置生效状态分开。先解决状态真假问题。
2. 改造主窗信息架构、平台菜单、设置分组和设备详情；保留已验证的配对与服务管理逻辑。
3. 首次向导、分步配对和权限恢复；接入发现、友好设备名及安全撤销。
4. 安全停止、运行时共享开关、托盘快捷操作和配置应用反馈。
5. 布局编辑配合边缘切换运行时；任务页配合完成确认、进度和取消能力；最后扩展启动项及通知。

先在现有 Fyne 下实现共同信息架构与可行的主题，不因视觉草案同时重写 SwiftUI 和 WinUI。若系统级无障碍、标题栏或菜单行为出现实际无法满足的要求，再单独评估原生外壳，记录双端维护与打包成本。不得将原型直接当成已接入后端的功能界面。

设计阶段不改服务行为。实现阶段按用户要求不追加 GUI 实机测试，通过状态模型、协议、进程生命周期及构建检查覆盖首次拒绝授权与恢复、双方确认、断线回本机、真实设置生效、撤销后不能连接、取消与失败不显示成功，以及关窗后台与真正退出的区别。

## 12. 2026-11-23 增强交互

Mac 权限页提供“自动请求授权”和“一键删除权限”。首次设置完成、前台打开时仅自动请求一次，最终授权由系统提示确认；拒绝后通过权限行恢复。删除前确认并停止共享及配对，仅重置 MyApp 的 TCC 授权，明确保留系统本地网络登记，不显示全部权限已删除。

添加电脑窗口自动进入限时可发现状态，同时显示附近电脑和 IP 添加入口；选择候选时先停止本机旧监听，再发起连接。核对短码时停止可配对广播。组播失效时仍通过有界 LAN 单播查询寻找对端，不静默信任发现结果。

电脑建立信任后自动连接并准备主屏跨机切换；删除额外启用开关、自动连接偏好开关及控制按钮入口。在线、可控制且声明屏幕能力时，鼠标跨边缘直接切换，无需停留；按比例落点，反向边缘返回本机。已有配置中的旧关闭值不阻止该行为。编辑位置先停止边缘控制，保存后同步到运行时；紧急退出关闭本次运行的自动跨屏，文字和文件偏好保持独立。

源端隐藏光标，目标端显示正常指针；本机恢复优先于网络确认。无法读取几何、确认隐藏或恢复时展示真实错误，不把控制状态留为成功。Mac 后台光标接口不受 Apple 稳定 API 保证，相关系统升级需回归检查；完整多物理显示器拓扑另行实现。

### 0.1.8 Windows 子电脑多屏

Windows 子电脑的扩展显示器组成一个连续桌面，按 Windows 实际排列跨越内部接缝，不在主屏与显示器2之间返回 Mac。负坐标、竖屏和错位排列以实际屏幕矩形为准，屏幕空隙不能积累不可见移动。进入子电脑时按桌面范围映射并落到实际显示器上，返回仍使用面向主电脑的外侧边缘。Mac 主电脑的跨机边界仍为主屏；两端更新到0.1.8才能使用本轮多屏能力。信任后自动生效，无需新增按钮或开关。

交接确认期间缓冲鼠标及键盘，确认成功后按顺序发送；失败或紧急退出立即停止并恢复本机。不能用后台测试宣称已达到实际无感切换，最终手感由双机人工验收确认。
