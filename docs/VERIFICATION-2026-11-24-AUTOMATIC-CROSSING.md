# 0.1.7-alpha 自动跨屏与权限通知修复

用户要求：主子电脑建立信任后自动生效，无需额外开启跨屏、结束向导或点击控制按钮。系统权限与对端在线仍是运行条件；主动暂停、紧急退出及撤销信任仍优先停止输入。

## 修复

- 桌面运行时忽略旧配置的跨屏关闭值，建立连接后自动准备边缘切换，去掉边缘停留。只有鼠标移过边缘时才捕获输入，键盘跟随目标，返回恢复本机。
- 信任建立后自动完成配对向导并连接；删除自动连接和跨屏开关、手动控制入口。等待配对进程退出后再启动服务，失败限频重试，可信电脑变化时自动更新连接。
- 保存/取消位置恢复编辑前的自动状态。短暂断线保留自动状态，重连不覆盖紧急退出及位置编辑；主动暂停时不自动更新服务。
- 移除权限预检系统通知，页面中显示具体项目；通知去重记录不再每次刷新重建。授权请求批次升为2，升级仅自动尝试一次，最终授权由系统确认。
- Windows 新包沿用现有 `E:\test\MyApp-0.1.6-alpha-edge\app\profile`，保留身份与信任，无须因升级重新配对。不存在旧配置时使用新包自己的 profile。旧数据目录应保留。
