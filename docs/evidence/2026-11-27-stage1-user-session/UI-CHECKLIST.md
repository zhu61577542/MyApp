# 桌面界面人工核查

日期：2026-11-27。版本：0.1.9-alpha；Mac 192.168.1.8，Windows 192.168.1.5。

本轮由用户操作界面，助手核对新增日志并记录反馈。第一阶段控制权组件尚未接入桌面程序，本表不用于证明实体双向跨屏已完成。第一阶段最终验收仍待用户确认。

| 顺序 | 操作与预期 | 结果 |
|---|---|---|
| 1 | 启动两端；窗口正常，菜单栏或托盘图标出现；记录设备页对端名称、在线状态和提示文字 | 待用户操作 |
| 2 | 切换设备、传输、权限与安全、设置页面；检查文字、布局、窗口缩放和系统明暗适配 | 待核查 |
| 3 | 查看屏幕布局与连接状态；已有信任应保留，自动跨屏不依赖点击控制按钮 | 待核查 |
| 4 | Mac实体鼠标跨到Windows、访问Windows两个显示器，再用同一只鼠标返回；观察光标隐藏与恢复、流畅度 | 待核查 |
| 5 | 暂停与恢复共享，核对界面状态及本机键鼠恢复；本轮不撤销信任或重置权限 | 待核查 |
| 6 | 关闭主窗口后从菜单栏或托盘重新打开；再次启动应唤起已有实例 | 待核查 |

每项用户反馈后记录实际结果和相应日志。发现故障则先记录并定位，不将未执行项目标为通过。Windows实体鼠标主动发起到Mac不在0.1.9已交付能力内。

记录范围：用户报告的操作、时间、程序状态与错误。未开启屏幕录制、原始键盘记录或剪贴板内容采集。
