# 第三阶段人工核查

日期：2026-11-28。状态：代码与后台验证完成，0.1.13-alpha-stage3原生GUI交付准备中；用户人工验收尚未开始，第四阶段未开始。

## 本轮可感知的变化

- Windows实体鼠标可自动触边进入Mac，沿用Mac侧的位置并自动互反，无需控制按钮。
- 被控端实体移动、按键或点击结束当前远程控制，恢复本机，连接保留。
- Mac本程序注入事件统一标记，捕获和被动监听排除它们，避免回流或虚假接管。
- Windows主屏与扩展屏均可作为来源，跨机只使用相邻方向整组桌面的最外侧；内部接缝和错位凹口继续留在Windows内。返回时落到实际显示器。
- 过渡状态抑制自动触边；新实体移动后持续采样最终落点；控制恢复不因远程注入的位置自动反弹。
- 状态栏按实际输入来源显示控制方向，并区分双方平台就绪与等待确认。完整去主副界面、配置迁移保留到第四阶段。

## 请逐项人工验收

1. 两端退出旧版后启动0.1.13，沿用身份、配对和位置；检查连接和权限就绪。
2. 用Mac鼠标进入Windows，在显示器1、2之间往返，再用同一只Mac鼠标返回。
3. 用Windows实体鼠标移向Mac相邻方向的整组桌面最外侧，进入Mac后再返回Windows。当前若Windows位于Mac左侧，应从Windows整组桌面的最右边缘进入Mac。
4. Mac鼠标控制Windows时，操作Windows实体键鼠；反向再做一次。应恢复被控端本机，旧来源光标恢复，两端保持连接。
5. 远程控制生效后，验证点击、滚轮、文字、修饰键和拖拽，不应因本程序注入触发实体接管或自动反弹。
6. 验证急停后不继续自动切换，恢复共享后可重新触边。
7. 留意重复切换、卡顿、光标异常或权限提示，反馈触发步骤与两端状态。

本阶段保留原连接角色配置；实机结果以用户逐项反馈为准。后台和原生测试使用替身，未自动拦截、注入或隐藏用户实体键鼠，不做GUI自动化。Windows所有内容只在E:\test。

验证证据见 docs/evidence/2026-11-28-peer-stage3/。记录程序启动、连接、控制、错误状态与用户反馈，不记录原始键鼠轨迹、按键内容、剪贴板内容或屏幕录像。
