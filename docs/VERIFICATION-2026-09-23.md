# 0.1.2-alpha 修复验证

本轮修复了 2026-09-22 需求核验中的 5 项失败，没有删除或放宽原有失败断言：重复输入注入、相同文字未推进远端版本、去环记录误吞后续本地复制、文件接收跟随缓存外符号链接、用户文件与续传状态文件重名。

接收端使用 os.Root 约束实际文件操作，并对符号链接进行检查；提交冲突后保留恢复状态，取消传输不删除链接指向的外部文件。恢复状态移出用户内容目录，旧 alpha 的未完成传输不自动迁移。缓存暂不恢复修改时间与目录权限，这一保真限制仍需解决。

运行时统一等待所有会话任务结束，随后才关闭注入器/捕获器；TLS/Hello 建连采用 5 秒超时，取消上下文可关闭正在等待 Hello 的连接。
